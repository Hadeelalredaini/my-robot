# My Quadruped Robot Project 🤖

A 3D-printed quadruped robot project designed using **Onshape** for mechanical CAD modeling and simulated/programmed with **Arduino** hardware integration.

---

## 🛠️ Tech Stack & Tools
* **CAD Modeling:** Onshape (for 3D robot body and assembly design)
* **Microcontroller:** Arduino Uno
* **Hardware Components:** Ultrasonic Sensor, Servo Motor
* **Simulation & Prototyping:** Tinkercad / Onshape Assemblies
